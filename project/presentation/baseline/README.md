# Prototype de présentation

Ce dossier contient le prototype HTML de référence. Il est volontairement sans thème définitif, sans dépendance réseau et sans interaction obligatoire.

## Mode

Le prototype est un support hybride, de complexité standard. Il déroule une histoire verticale avec des schémas SVG, des tableaux, une matrice de risques et des encadrés visibles. Le lecteur n'a pas besoin de cliquer pour comprendre le fil.

## Ouvrir le prototype

Depuis le dossier `project/`, lancez un serveur local pour conserver les liens vers les notes et l'analyse :

```bash
python3 -m http.server 8000
```

Puis ouvrez `http://localhost:8000/presentation/baseline/`.

## Sources

Le contenu renvoie aux notes de contexte et aux modules d'analyse. Les nombres et les scores ne sont pas des données simulées cachées. Les scores sont explicitement pédagogiques.
