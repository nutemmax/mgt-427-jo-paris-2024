# Présentation

Cette section transforme l'analyse en récit de diapositives.

- [`brief.md`](brief.md) définit la thèse, l'ordre des diapositives, les visuels et les critères d'acceptation.
- [`baseline/`](baseline/) contient le prototype HTML sans thème définitif.

Le prototype est un point de départ. Il doit être relu avec le contenu avant toute décision sur la palette, les images et l'animation.
